## Overview

Tantra is a polyphonic MIDI arpeggiator and note sequencer with up to 32 independent note lanes, each with its own rhythm, velocity, and pitch offset, for intricate polyrhythmic MIDI patterns.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **DS Audio Tantra** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **32 Note Lanes** | Each lane has independent pitch, velocity, gate, and rhythm settings |
| **Polyrhythm Mode** | Different step counts per lane create evolving polyrhythmic patterns |
| **Chord Input** | Input chords and route notes to lanes based on chord voice ordering |
| **MIDI Output** | Route lane outputs to individual MIDI channels for multi-timbral use |
